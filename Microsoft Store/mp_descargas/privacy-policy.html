🧩 Extensión de Navegador MP Tools - Mercado Público
Compatibilidad: Google Chrome & Microsoft Edge

Política de Privacidad

Esta política explica el tratamiento de la información, el alcance de los permisos solicitados y los compromisos de protección de datos de la extensión de navegador MP Tools - Mercado Público.

Versión actual: 4.4.0 (Manifest V3)
Última actualización: 26 de septiembre de 2026
Titular / Desarrollador: Solvitu / SoyKoda
Contacto: contacto@solvitu.com

01 Propósito Único (Single Purpose)

MP Tools - Mercado Público es una extensión de productividad diseñada con el propósito exclusivo de agilizar la consulta, descarga estructurada de antecedentes y sincronización de información de procesos de compras públicas (órdenes de compra, licitaciones y compras ágiles) en el portal oficial de compras del Estado de Chile (mercadopublico.cl).

La extensión asiste a compradores y proveedores facilitando tareas operativas como la descarga masiva de adjuntos en subcarpetas locales y la visualización organizada de antecedentes en la plataforma web compañera SoyKoda (soykoda.cloud).

02 Permisos Solicitados en manifest.json y Justificación Técnica

De acuerdo con las políticas para desarrolladores de la Chrome Web Store y Microsoft Edge Add-ons, la extensión solicita únicamente los permisos estrictamente indispensables para cumplir con su propósito:

Permiso Tipo Justificación técnica
downloads API de Navegador Permite guardar en la carpeta de "Descargas" local del usuario los archivos adjuntos de licitaciones y cotizaciones organizados en subcarpetas numeradas por proveedor.
scripting API de Navegador Permite inyectar elementos visuales amigables (botones de descarga, indicadores de progreso y cuadro de carga masiva desde Excel) en las páginas del portal de Mercado Público.
offscreen API de Navegador (MV3) Permite crear un entorno de procesamiento en segundo plano para analizar documentos HTML legados (WebForms) y transformarlos a estructuras JSON mediante DOMParser, dado que los Service Workers de Manifest V3 no disponen de APIs de manipulación de DOM.
https://*.mercadopublico.cl/* Host Permission Permite interactuar exclusivamente con el portal de compras públicas de Chile y sus subdominios de servicios (ej. servicios-compra-agil.mercadopublico.cl). No se solicitan permisos sobre ningún otro sitio web de navegación general.
Inyección en soykoda.cloud y localhost:3000 Content Script Inyecta el puente de mediación local (soykoda_bridge.js) para permitir la comunicación bidireccional segura entre la extensión y la aplicación web del usuario cuando este solicita explícitamente sincronizar antecedentes.

03 Declaración Explícita de "Cero Custodia de Credenciales"

Línea Roja de Privacidad: La extensión jamás lee, almacena, transmite ni tiene acceso a contraseñas, credenciales de ClaveÚnica, tokens de autenticación permanentes ni códigos de segundo factor (2FA).

El inicio de sesión y la autenticación se realizan de manera 100% aislada en los servidores oficiales de Mercado Público y ClaveÚnica (Gobierno de Chile).

La extensión no gestiona credenciales ni interviene en el formulario de inicio de sesión: opera única y exclusivamente aprovechando la sesión activa preexistente en el navegador web del usuario a través de cookies de sesión automáticas y efímeras, las cuales jamás se exportan fuera del entorno local del navegador.

04 Alcance de los Datos Procesados y Propósito

La extensión accede exclusivamente a información de procesos de compras públicas:

  • Información de Procesos: Código de orden de compra, código de licitación, cotizaciones de Compra Ágil, nombres de proveedores, montos ofertados, estados de convocatoria y metadatos de documentos adjuntos.
  • Momento de Acceso: La lectura y sincronización se efectúan única y exclusivamente cuando el usuario hace clic o solicita la acción de manera explícita (por ejemplo, pulsando el botón "Sincronizar con Mercado Público" desde la plataforma web compañera SoyKoda o pulsando los botones de descarga masiva en el portal).
  • Propósito: Permitir la visualización organizada de antecedentes, cálculo comparativo de ofertas y análisis normativo asistido en el panel de SoyKoda.

05 Flujo Local y Cumplimiento de "Limited Use"

En estricto cumplimiento del programa de Uso Limitado (Limited Use Policy) de la Chrome Web Store y Microsoft Edge Partner Center:

Compromiso Taxativo: Los datos procesados por la extensión NO se venden, arriendan, comercializan ni transfieren a terceros con fines publicitarios, de telemercadeo ni de perfilamiento crediticio.
  • Transferencia Local en el Navegador: La comunicación entre la extensión y la aplicación web SoyKoda ocurre localmente mediante el API window.postMessage con verificación rigurosa de origen (event.origin) y nonces únicos anti-spoofing. No viajan datos a servidores de terceros intermediarios.
  • Sin Uso para Publicidad: La información no se utiliza para mostrar anuncios ni para construir perfiles de comportamiento comercial.
  • Sin Entrenamiento de Modelos Públicos: Los datos procesados localmente no se emplean para entrenar modelos generales de inteligencia artificial con información privada del usuario.

06 Procesamiento en Entorno Offscreen (chrome.offscreen)

El portal de Mercado Público cuenta con módulos construidos sobre tecnologías ASP.NET WebForms legadas, cuyas tablas y paginaciones requieren análisis del árbol DOM.

Dado que los Service Workers de Manifest V3 no tienen acceso al objeto document ni a la API DOMParser, la extensión instancia un documento offscreen interno aislado (offscreen.html) con la justificación técnica DOM_PARSER.

  • El entorno offscreen se utiliza exclusivamente para convertir fragmentos de HTML a JSON estructurado.
  • No ejecuta scripts remotos de ningún tipo.
  • No realiza peticiones de red directas ni monitorea la actividad de otras pestañas o ventanas del usuario.

07 Retención de Datos y Control del Usuario

La extensión opera bajo un modelo de memoria volátil:

  • No utiliza bases de datos locales persistentes ni almacena historiales de navegación dentro del navegador.
  • Cualquier información temporal o token efímero capturado en memoria para consultas inmediatas se elimina automáticamente al cerrar la pestaña o recargar el navegador.
  • Persistencia Opcional en SoyKoda: Si el usuario decide conscientemente guardar un snapshot de antecedentes en su cuenta de SoyKoda, los datos viajan directamente hacia su cuenta privada en la plataforma bajo la Política de Privacidad de SoyKoda, donde el usuario puede solicitar su eliminación en cualquier momento.
  • Desinstalación: El usuario puede remover la extensión en cualquier momento desde el menú de extensiones de su navegador (chrome://extensions o edge://extensions), lo que elimina inmediatamente cualquier residuo local de la extensión.
